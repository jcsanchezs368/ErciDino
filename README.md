# ErciDino
### Introdución
ErciDino es un videojuego 2D estilo plataforma creado en Unity. 
El objetivo principal es llegar al final de los tres niveles con un mínimo de 5 monedas.
Cuidado con los enemigos, caídas al vacío o trampas, dificultarán tu travesía por los niveles.
Cada nivel cuenta con 3 vidas, cada vida cuenta con 3 corazones, en caso de que el nivel de vidas llegue a cero, si mueres no podrás reaparecer.
Hay consumibles por el mapa, corazones y guindillas picantes, agarrar una guindilla restaura todas las bolas de fuego. Los corazones restauran un corazón perdido.

### Controles
A, D o Flecha izquierda y flecha derecha- Moverse horizontalmente
W, espacio - Saltar
Left shift - Correr
F - Dar patada
C - Disparar proyectil
